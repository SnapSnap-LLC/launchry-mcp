# launchry-mcp

Official Launchry MCP client.
Follow the [agent setup guide](https://launchry.dev/install/agent.md).

Configure the stdio server as `npx --yes launchry-mcp@latest`. This server shares the local launchry-cli login.

Build from source: `npm ci && npm run build` (Node.js 20.19 or newer).

## See an example

Watch the [Dayfold product demo](https://launchry.dev/skills/launchry-cold-start). The 16-second sample and its three-shot breakdown show how to present one feature through a starting screen, an action, and the result.
